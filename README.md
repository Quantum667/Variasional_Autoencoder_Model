# Variational Autoencoder Model

## Что это?

**VAE** - модель исскуственного интеллекта, умеюща сжимать сложные данные (изображения например) в компактный вектор, а затем восстеавливать данные (или похожие на них) из полученного вектора

## Как это работает?

Сама модель состоит из трех частей:
- **Енкодер** (Encoder) - часть, ответственная за кодировку данных в вектор
